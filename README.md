🌍 Wonderlust – Travel Itinerary Planner

Wonderlust is a full-stack travel itinerary planning web application that enables users to explore destinations, create listings, and manage travel experiences efficiently.
Built using the MERN stack principles, the application demonstrates strong fundamentals in scalable backend design, RESTful APIs, and cloud integration.

🧠 Project Overview (For Recruiters)

Developed a full-stack web application with structured MVC architecture

Implemented authentication & authorization for secure user actions

Integrated cloud storage (Cloudinary) for handling media uploads

Designed RESTful APIs for seamless frontend-backend communication

Focused on clean code practices, modular design, and scalability

🚀 Key Features

✈️ Create, edit, and delete travel listings

🖼️ Image upload & storage via Cloudinary

⭐ Ratings and reviews system

🔐 Secure authentication & role-based authorization

🔎 Filtering and browsing of destinations

📱 Responsive and user-friendly UI
